# AutoBotAI Explorer Bot protocol v1 — conformance vectors.
#
# The SAME file is run against:
#   - the firmware core (C++, test/host/test_core.cpp, `npm run test:firmware`)
#   - the browser's simulated device (TypeScript, src/features/hardware/tests)
# so the simulated device cannot drift from the firmware logic.
#
# Syntax (one instruction per line):
#   === <name>              start a new case (fresh core)
#   BOOT <ms> <poweron|watchdog|other> <seed>
#   @ <ms>                  advance the clock to <ms> and tick once
#   ~ <ms> <step>           tick every <step> ms up to <ms> (no host traffic)
#   ~p <ms> <step>          same, sending "PING n" before each tick (PONG lines are discarded)
#   > <line>                host sends <line> at the current time ($S = session from the last HELLO_OK)
#   < <prefix>              the next device line (TEL lines excluded) must start with <prefix>
#   <! nothing              no device line (TEL excluded) is waiting
#   ? <k=v> ...             outputs/state: st=, en=, l=, r=
#   T <k=v> ...             the latest TEL line contains every token
#   D <mm> <ok|range|err|none>   new distance sample at the current time
#   CLEAR                   drop waiting device lines
